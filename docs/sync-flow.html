Alice / workflow reference

From magnet to local files.

The complete sync execution flow: prepare a private Transmission server, bring downloads home, then retire the deployment.

$ alice sync --verbose
PrepareConvergeDownloadFinalizeTeardown

Read from top to bottom.
Every step depends on the preceding step succeeding.

The download loop is collapsed into one node to keep the dependency graph acyclic.

01
Prepare

Configuration & state

Normalize settings, validate the deployment identity, acquire the deployment lock, and record the operation. The lock prevents concurrent controllers from interfering.

02
Prepare

Require deletion permission

Require compute-prevent-destroy: false explicitly in YAML. Successful sync ends by destroying the deployment.

03
Prepare

Check the local copy destination

Verify rsync supports --protect-args and the destination is writable before provisioning. Repeat these checks before every copy.

04
Converge

Cloud preflight

Check provider scope, existing cloud resources, and configuration drift before making changes.

05
Converge

Prepare local SSH authority

Prepare missing client and bootstrap host keys, record generated-file ownership, and prepare cloud-init. Existing files are never adopted.

06
Converge

Converge cloud infrastructure

Bind the VPC identity; ensure the deployment tag, firewall, and droplet; reconcile firewall rules; wait for readiness.

07
Converge

Establish pinned SSH trust

Rotate away from the bootstrap host key and verify its replacement. Trust is bound to the recorded instance.

08
Converge

Provision Transmission

Update apt indexes → install Transmission, AppArmor tools, and rsync → disable and verify the incompatible AppArmor profile → stop the service → write settings and prepare download permissions → verify settings and start the service. RPC binds to loopback only.

09
Converge

Verify the web UI & RPC

Open a pinned, loopback-only SSH tunnel. Require a working web UI and successful RPC session-get.

10
Converge

Record convergence & install alias

Complete the durable provisioning intent, resolve matching interrupted attempts, and install Alice’s owned SSH alias.

11
Download

Open the download tunnel

Open the tunnel used throughout downloading and verify the web UI again.

12
Download

Submit & start torrents

Add the configured magnets and explicitly start the requested torrent hashes.

13
Download

Poll progress & copy incrementally

Check torrent errors and progress, then run incremental rsync. Every requested torrent must have complete metadata, 100% progress, and zero bytes remaining. Otherwise wait 10 seconds and repeat.

↻ Check → copy → wait 10 seconds → repeat until complete
14
Finalize

Stop Transmission

Stop the service and verify it is inactive. Files must remain stable for the final copy.

15
Finalize

Perform the final checksummed copy

Run rsync with --checksum to detect differences incremental copying may have missed. Rsync never uses --delete.

16
Teardown

Verify teardown safety

Recheck deletion protection, recorded cloud ownership, and local SSH cleanup safety. Retain unrecorded SSH files; changed recorded keys or unsafe paths block deletion.

17
Teardown

Delete owned cloud resources

Delete and verify removal of the droplet, firewall, then owned deployment tag. Retain the shared VPC.

18
Teardown

Clean up local authority

After cloud resources are gone, remove the owned SSH alias and verified generated SSH files. Report retained unrecorded files.

19
Teardown

Record success & release resources

Close the tunnel, record success, and release the state lock. Keep controller state for receipts and recovery history.

Failures preserve the deployment

Download errors, copy failures, or Ctrl-C before teardown prevent automatic deletion. Once cloud deletion has begun, an interruption can leave partial teardown for a later delete to reconcile. Direct delete does not perform the final download copy.

An empty list still brings files home

With no magnets, sync skips torrent starting and the polling/copy loop. It still stops Transmission, completes the final checksummed copy, and tears down. Local files are never removed by rsync.
