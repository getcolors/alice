Alice

Private Transmission on DigitalOcean. Python and PocketDeploy handle deployment, verified SSH, recovery and safe download copying.

alice init
alice plan
alice converge
alice tunnel
alice sync

RPC stays on loopback behind an SSH tunnel. Sync stops Transmission and verifies a final checksummed copy before deleting the deployment. Failures retain resources; deletion requires protection explicitly disabled.

PocketDeploy supplies cloud ownership, state, VPC discovery and SSH authority. Alice supplies only Transmission and download ordering. No Terraform or Ansible is required.
