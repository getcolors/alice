GREEN PACKAGE SKILL · DIGITALOCEAN · TRANSMISSION

alice

One DigitalOcean Droplet running Transmission, with a managed SSH alias and a web UI that listens only on loopback.

Private by construction. Use an SSH local forward to reach Transmission. Do not publish its RPC port.

Quick start

npx skills add getcolors/alice
cp .agents/skills/package-alice-green/green ./green
./green validate
./green build
./green create --dry-run
./green create
./green tunnel 19091

While the foreground tunnel runs, open http://127.0.0.1:19091/transmission/web/. Create performs the same tunnel check before returning successfully.

Workflow

create   start → infrastructure → local SSH → Transmission → tunnel acceptance
delete   start → remove local SSH alias → guarded infrastructure → cleanup
validate state + tools + credentials + DigitalOcean authentication
describe local alias + SSH reachability + Transmission service status

Desired state

DigitalOcean

Name, region, size, image, an existing VPC UUID, and one existing SSH key identifier.

Transmission

Remote RPC port and default local tunnel port. RPC binds to 127.0.0.1.

State

Local, S3, or R2 OpenTofu backend under a package-specific state key.

Credentials

COLORS_PAR_DO_TOKEN and optional backend credentials remain in the process environment.

See the configuration reference for all keys. SSH is the RPC authentication boundary; Ubuntu 24.04's broken Transmission AppArmor notify profile is disabled so systemd can supervise the daemon.

Safety

  • Never export COLORS_PAR_PROFILE.
  • Keep compute-prevent-destroy: true in committed desired state.
  • Never edit or commit .colors/.
  • Run build and create --dry-run before real operations.

Recovery

Repeated create converges the existing Droplet. If Transmission fails, inspect systemctl status transmission-daemon and its journal over SSH. Preserve local OpenTofu state until deletion; if it is lost, recover or import the Droplet before destroying anything.
